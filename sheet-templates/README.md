# sheet-templates

En-têtes de référence des onglets du Google Sheet, avec des **lignes fictives**.

> ⚠️ Ces fichiers ne contiennent **aucune donnée réelle** et ne doivent jamais en contenir :
> le dépôt est public (C1). Toutes les adresses sont en `@example.com`, un domaine réservé
> par la RFC 2606 qui ne peut recevoir aucun mail.

Ils servent de documentation et de jeu de test. **Il n'est pas nécessaire de les importer** :
la fonction `initialiserSheet()` de `apps-script/Sheet.gs` crée les 8 onglets, les en-têtes,
les listes déroulantes et les formules à partir d'un classeur vide.

`Reponses`, `Historique` et `Journal` sont écrits par le script : leurs lignes d'exemple
montrent le format attendu, elles n'ont pas à être saisies.

Voir [`../docs/MODELE_DONNEES.md`](../docs/MODELE_DONNEES.md) pour le dictionnaire complet.
